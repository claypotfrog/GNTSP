<p spacebelow=10>If you do a lot of work creating, deleting, and /or sharing vocabulary lists and groups, then you are going to see a lot of warnings.  Every time you delete anything, the program will ask you for confirmation because deletions are permanent.  But if you are deleting a lot, this can get tiresome.  So you can turn the delete warnings off.  On the main "Vocabulary" page, click the blue gear "Settings" icon in the upper left.  This brings up the Vocabulary Settings dialog box.  Below the "Reset Vocabulary Statistics" button is the checkbox labeled "Show Vocabulary Delete Warnings".</p>
<p spacebelow=10><img src="binfile:help/images/max-interval-6.png"></p>
<p spacebelow=10>Uncheck that checkbox, and now the program will never ask for confirmation for a vocabulary deletion.  Press "Delete", and it's gone.  This is true for deleting Vocabulary List and Groups as well as shared Vocabulary Lists and Groups.  This change remains the default every time you run the program.  If you want to turn the warnings back on, you must do so by re-checking the checkbox in the "Settings" dialog.</p>
<p spacebelow=10>In addition, if you create a number of vocabulary groups by typing or pasting words directly into the Bulk Add field of the vocabulary creator page, every time you click the "Add Words" button, if there are any words in the field which the app cannot identify, then you will receive a warning and those words will remain in the field.  You can also turn this warning off.  So the second item on the Settings dialog box is labeled "Show Vocabulary Import Warnings".  Uncheck this box to turn off the error messages when a word cannot be identified.  The word will simply be left in the field.</p>
<p spacebelow=10>As with turning off the delete warnings, this change remains the default every time you run the program.  If you want to turn the warnings back on, you must do so manually by re-checking this checkbox in this dialog.</p>
